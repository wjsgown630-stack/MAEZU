|# Git & GitHub 기초 학습 정리 (2026-10-14)

## 1. 로컬과 원격 저장소

| 구분 | 로컬(Local) | 원격(Remote) |
|---|---|---|
| 의미 | 개인 컴퓨터에 있는 저장소 | GitHub에 있는 저장소 |
| 위치 | 내 컴퓨터 | GitHub 서버 |
| 다른 사람의 접근 | 일반적으로 직접 공유하지 않으면 접근하기 어려움 | 공개 저장소는 다른 사람도 볼 수 있음 |

## 2. GUI와 CLI

| 구분 | GUI | CLI |
|---|---|---|
| 의미 | 그래픽 사용자 인터페이스 | 명령줄 인터페이스 |
| 사용 방법 | 버튼과 아이콘 사용 | 문자와 명령어 사용 |
| 예시 | GitHub Desktop | 터미널 |

## 3. Git 작업 흐름

```text
       GitHub (원격 저장소)
                │
          Clone (복제)
                ↓
       내 컴퓨터 (로컬 저장소)
                │
          Add (변경 사항 준비)
                ↓
        Commit (변경 사항 기록)
                │
          Push (원격에 업로드)
                ↓
       GitHub (원격 저장소)
```

## 4. 주요 용어

- **Clone:** 원격 저장소를 로컬로 복제하는 것
- **Add:** 커밋할 변경 사항을 준비하는 것
- **Commit:** 변경 사항을 기록하는 것
- **Push:** 로컬의 커밋을 원격 저장소에 올리는 것
- **Pull:** 원격 저장소의 변경 사항을 가져와 로컬에 반영하는 것
- **.git:** Git의 변경 기록과 저장소 설정 등 관리 정보가 들어 있는 디렉터리
- **Visual Studio Code (VS Code):** 코드를 작성하고 편집하는 프로그램

## 5. 파일 및 프로그램 사용

- **Win + E:** Windows 파일 탐색기 열기
- **GitHub Desktop:** 버튼과 그래픽을 이용해 Git 작업을 할 수 있는 프로그램
- **터미널:** 명령어를 입력해 Git 작업을 할 수 있는 환경

## 6. GitHub와 데이터

- GitHub는 서버를 통해 저장소와 파일을 보관하고 제공한다.
- GitHub 저장소는 공개 또는 비공개 설정에 따라 다른 사람의 접근 여부가 달라진다.
- 프론트엔드에서 새로고침하면 일부 화면 상태가 초기화될 수 있지만, 저장 위치에 따라 데이터가 유지될 수도 있다.
- GitHub Pages를 이용하면 정적인 프론트엔드 웹사이트를 배포할 수 있다.

## 7. 오늘의 핵심 요약

- 로컬 = 내 컴퓨터의 저장소
- 원격 = GitHub의 저장소
- GUI = 버튼과 아이콘으로 작업
- CLI = 명령어로 작업
- Clone = 원격 저장소 복제
- Add = 커밋할 변경 사항 준비
- Commit = 변경 사항 기록
- Push = 원격 저장소에 업로드
- Pull = 원격의 변경 사항을 가져와 로컬에 반영
- .git = Git 저장소 관리 정보를 담은 디렉터리
